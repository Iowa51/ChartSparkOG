2. AGENT API ROUTE GROUP
Create src/app/api/agent/complete-session/route.ts

POST handler:
- Authenticate request using existing auth pattern from other API routes
- Get clinician organization subscription_tier from Supabase
- Determine feature set based on tier:
  starter/pro → mode: 'documentation_only'
  complete → mode: 'full_pipeline'
- Build request body for agent-orchestrator:
  {
    sessionId,
    clinicianId,
    patientId,
    inputMode: 'text',
    clinicianInput,
    noteFormat: noteFormat || 'SOAP',
    sessionType,
    duration,
    payerType: payerType || 'commercial',
    mode
  }
- POST to AGENT_ORCHESTRATOR_URL/sessions/:sessionId/complete
- On success (documentation_only mode):
  Update clinical_notes: set subjective, objective, assessment, plan 
  from generated note, set status to 'pending_review'
  Update encounter status to 'completed'
  Return { success: true, mode, note, cptCode, icd10Codes,
  qualityScore, confidence }
- On success (full_pipeline mode):
  Update clinical_notes with generated note
  Update encounter status to 'completed'
  Create audit_flags record for any agent flags
  Return { success: true, mode, note, cptCode, icd10Codes,
  qualityScore, confidence, billingResult, reimbursementEstimate,
  requiresReview }
- On error: return { success: false, error, fallback: true }
  NEVER block the clinician — they can still save manually on failure
