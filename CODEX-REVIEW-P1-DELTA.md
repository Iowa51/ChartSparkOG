# CODEX-REVIEW-P1-DELTA - Sprint 0 / P1 remediation delta review

**Reviewer:** Codex (independent reviewer; did not author the remediation)
**Scope:** Delta review requested in `_cc-prompts/sprint0-codex-delta.txt`
**Date:** 2026-07-07

## Verdict: APPROVE-WITH-FIXES

The high-risk database remediations are substantively correct. SM-1 and SM-2 are closed by the new intake trigger, the trigger recreation does not weaken the previously reviewed UPDATE/DELETE lock behavior, `test:db` is now wired to a dedicated DB config and fails on zero collected tests, CI gates `build` on the DB job, and the vitals/sibling RLS policies match the item-7 command matrix.

Two low-severity follow-ups remain: the app-level `getPatientLatestVitals` org predicate is still optional and therefore bypassable by future callers who omit `organizationId` (RLS still blocks normal cross-org reads), and the app-side `generate-note` gate is verified only by static review, not by a route/helper regression test.
